# SQL Murder Mystery

## Project Overview

This project uses SQL to investigate a fictional murder in SQL City.

The objective is to analyse several related database tables, follow witness evidence, narrow down suspects, and identify the person responsible.

## SQL Skills Used

- SELECT
- WHERE
- AND
- LIKE
- ORDER BY
- LIMIT
- JOIN
- Multiple-table JOINs
- Table aliases
- Relational database analysis

## Tables Used

- crime_scene_report
- person
- interview
- drivers_license
- get_fit_now_member
- get_fit_now_check_in

## Investigation Process

1. Located the murder report.
2. Identified the witnesses.
3. Reviewed witness interviews.
4. Investigated gym membership records.
5. Analysed gym check-in data.
6. Investigated vehicle registration evidence.
7. Combined evidence across several tables to narrow down suspects.
